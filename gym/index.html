WebGym: A Benchmark for Web Security Evaluation

WebGym is a benchmark for evaluating the vulnerability discovery and exploitation capabilities of web security tools and AI agents.

Why Black-Box Evaluation?

Black-box evaluation assesses both exploration and exploitation without source-code access. Exploring real application functionality can take substantial time, so we use a limited set of applications and increase vulnerability density by inserting newly generated variants. This allows more exploitation challenges within each explored application. New variants and insertion contexts also help reduce the risk of prior exposure through model training data.

Why White-Box Evaluation?

White-box evaluation will use a large collection of applications with 0-day / 1-day vulnerabilities. With source-code access, tools will be evaluated on code understanding, vulnerability reasoning and exploit validation across that collection. Our aim is to assess generalization to new vulnerability cases and reduce the influence of prior exposure through model training data.

BLACK-BOX BENCHMARK

The Black-Box Benchmark

Our black-box benchmark pairs runnable web applications with known vulnerabilities and verifiable PoCs. Tools explore each application through its web interface; evaluators use the reference evidence to assess their findings.

BENCHMARK ADVANTAGES

Why Choose WebGym for Black-Box Evaluation?

Real vulnerabilities in real application functionality

Variants derived from real CVE root causes are embedded in working applications. Finding them means navigating real inputs, application state and business logic.

Variants with different difficulty levels

Variants derived from the same real vulnerability root cause retain different combinations of flawed security defenses, creating difficulty levels that help distinguish tools' ability to bypass them.

Inserted into real application functionality

Every variant is inserted into real application functionality, so tools must navigate real input handling, application state and business context to reach and exploit it.

A verifiable PoC for every vulnerability

Each benchmark vulnerability comes with an executable PoC that reaches and triggers it in the target application, providing concrete evidence for validation.

ACM CCS 2026

PHPBench: Automated Generation of Verifiable and Hierarchical Benchmarks for PHP Web Fuzzing

Youkun Shi, Yuan Zhang, Lei Zhang, Jiarun Dai, Tianhao Bai, Fengyu Liu, Bocheng Xiang, Xiapu Luo, Min Yang

PHPBench constructs hierarchical vulnerability benchmarks by systematically weakening security protections derived from real vulnerability causes. It embeds the resulting variants into real application functionality and verifies each inserted vulnerability with an executable proof of concept.
